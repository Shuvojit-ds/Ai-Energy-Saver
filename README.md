# ⚡ AI Energy Saver

## AI-Powered Electricity Consumption, Cost Prediction & Energy Saving Platform

AI Energy Saver is an AI/ML-based platform that helps users understand electricity consumption, estimate electricity costs, predict energy usage, identify high-consumption patterns, and get energy-saving recommendations.

## 🎯 Problem Statement

Electricity bills show total consumption and cost, but they do not clearly explain:

* Which appliance consumes the most electricity
* How much each appliance contributes to the bill
* Which time periods have high consumption
* Which months or seasons have higher usage
* How future electricity consumption may change
* How users can save energy and reduce cost

## 💡 Solution

AI Energy Saver provides:

* Electricity consumption analysis
* Appliance-wise energy analysis
* Electricity cost calculation
* Machine Learning-based prediction
* Seasonal analysis
* Energy-saving recommendations
* RAG-based AI Advisor
* Agentic AI capabilities
* Electricity reports
* CSV export

## ✨ Features

### 📊 Energy Dashboard

* Total electricity consumption
* Estimated electricity cost
* Daily and monthly usage
* Appliance-wise consumption

### 🔌 Appliance Analysis

Analyze electricity usage of appliances such as:

* Laptop
* Fan
* Lights
* TV
* Other electrical devices

### 🤖 Machine Learning

The project uses **Ridge Regression** to predict electricity consumption from historical data.

### 🌦️ Seasonal Intelligence

Analyze electricity consumption across:

* Summer
* Monsoon
* Winter

### 🧠 RAG & Agentic AI

The AI Energy Advisor provides contextual energy-saving suggestions based on consumption information and relevant knowledge.

### 💰 Cost Calculation

```text
Electricity Cost = Energy Consumption × Electricity Rate
```

Example:

```text
100 kWh × ₹7.5 = ₹750
```

### 📄 Energy Report

Generate reports containing consumption, cost, appliance usage, seasonal information, and recommendations.

### 📥 CSV Export

Export analyzed data for further use in Excel, Python, or Power BI.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Shuvojit-ds/Ai-Energy-Saver.git
```

### Open the project

```bash
cd Ai-Energy-Saver
```

### Install dependencies

```bash
npm install
```

### Run the project

```bash
npm run dev
```
